## ⚡ درباره پروژه
سیستم **shahinDIGITAL** یک زیرساخت مانیتورینگ و ارزیابی امنیتی پیشرفته است که بر پایه‌ی یک سرور پرقدرت روبی (Ruby/WEBrick) و پنل فرانت‌اند سایبرپانک (Tailwind CSS) توسعه یافته است. این سیستم قابلیت دریافت و پمپاژ فریم‌های زنده، ثبت داده‌های محیطی و دسترسی ساختاریافته به گره‌های هدف را فراهم می‌کند.

---

## 📂 ساختار پوشه‌ها و فایل‌ها
- `server.rb` : هسته مرکزی سرور روبی برای مدیریت پورت‌ها، استریم‌ها و تفکیک پوشه‌ها بر اساس IP هدف.
- `target_screenshare_*` : مسیر ذخیره‌سازی خودکار لاگ‌ها، مشخصات سخت‌افزاری و فریم‌های صفحه نمایش هدف.
